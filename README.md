# КардиоЛог (KardioLog)

Дневник артериального давления для Android. 

## О приложении
«КардиоЛог» — это современное и удобное приложение для мониторинга артериального давления и пульса.

### Основные функции (v0.2):
- **Учет замеров**: Хранение данных о систолическом, диастолическом давлении и пульсе (Room DB).
- **Классификация АД**: Автоматическое определение категории давления по стандартам.
- **Тегирование**: Возможность помечать замеры («Покой», «Стресс», «После еды» и т.д.).
- **Графики и статистика**: Визуализация данных с помощью библиотеки Vico.
- **Сканирование**: Ввод данных с помощью камеры (ML Kit Text Recognition).
- **Отчеты**: Генерация PDF-отчетов для врачей с поддержкой кириллицы.
- **Напоминания**: Настройка утренних и вечерних уведомлений (WorkManager).
- **Темная тема**: Поддержка системной темной темы.

## Технологический стек
- **UI**: Jetpack Compose + Material 3.
- **Architecture**: MVVM + Repository Pattern.
- **Persistence**: Room (замеры, заметки), DataStore (настройки).
- **Background Tasks**: WorkManager.
- **Navigation**: Compose Navigation (Bottom Bar).

## Установка и сборка
1. Склонируйте репозиторий.
2. Откройте проект в Android Studio (Koala или новее).
3. Дождитесь синхронизации Gradle.
4. Запустите на устройстве или эмуляторе (API 26+).

---
*Приложение носит информационный характер и не заменяет консультацию врача.*
